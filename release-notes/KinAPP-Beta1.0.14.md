# KinAPP Beta1.0.14

## 更新内容

- 修复“我”页面进入时先显示旧缓存 `Lv.1 / 经验 0`，随后再跳到真实等级经验的问题；现在优先使用上次成功同步的成长缓存，首次无缓存时只显示同步状态，不再渲染错误等级。
- 优化 AI 推荐 OCR 的图像预处理：计分板固定区域会额外生成高对比与亮字二值化版本，再分别进行中英文识别。
- 重写计分板解析优先级：比分优先读取左侧比分区域，避免顶部倒计时 `0:03` 被误判；经济和 K/D/A 优先从队伍行、统计列、计分板主体等固定区域解析。
- 增加按行解析“玩家名 + 金钱 + 杀敌/死亡/助攻”的逻辑，减少把存活人数、半场比分等无关数字识别成 KDA 的情况。
