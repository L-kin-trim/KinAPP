# KinAPP Beta1.0.15

## 更新内容

### 发帖与 Markdown
- 日常闲聊帖改为「填写标题 + 添加正文」的发布方式，正文支持 Markdown 编写（标题、加粗、列表、引用、代码、链接等）。
- 道具分享帖、战术分享帖保持原有固定格式表单，需按字段填写。
- 帖子详情页对 Markdown 格式的日常帖进行前端渲染；非 Markdown 文本仍按普通文本展示。
- 日常帖更新弹窗同步支持编辑标题与 Markdown 正文。
- 后端 `forum_post` 增加独立 `title` 字段，日常帖标题不再只取正文前 40 字。

### AI 推荐页
- 隐藏 AI 推荐页顶部的「AI 战术与内容助手」入口卡片，页面聚焦计分板 OCR 与战术推荐。
- 按真实 CS2（16:9）计分板的固定布局重写裁切区域：地图标题、左侧两队大比分、上/下队伍行各自独立裁切识别。
- 比分改为直接读取左侧两队的大数字（如 9:2 / 5:0），更稳定；保留倒计时过滤，忽略 `0:03`、`1:09` 这类带前导零秒数的时钟。
- 玩家行解析改为「行末固定 5 个数字 = 杀敌/死亡/助攻/爆%/伤害，己方多一个金钱在前」的规则，对名字含数字（如 bj30380773、用户5061991、Shanghai1tao）和行首段位数字都稳健。
- 同一队伍取二值化与增强两种识别结果中更完整的一份，避免重复行。
- 计分板二值化改为自适应亮度阈值，按截图自身明暗自动调整。
