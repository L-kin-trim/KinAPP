# KinAPP Beta1.0.15

## 更新内容

### 发帖与 Markdown
- 日常闲聊帖改为「填写标题 + 添加正文」的发布方式，正文支持 Markdown 编写（标题、加粗、列表、引用、代码、链接等）。
- 道具分享帖、战术分享帖保持原有固定格式表单，需按字段填写。
- 帖子详情页对 Markdown 格式的日常帖进行前端渲染；非 Markdown 文本仍按普通文本展示。
- 日常帖更新弹窗同步支持编辑标题与 Markdown 正文。
- 后端 `forum_post` 增加独立 `title` 字段，日常帖标题不再只取正文前 40 字。

### AI 推荐页
- 隐藏 AI 推荐页顶部的「AI 战术与内容助手」入口卡片，页面聚焦计分板 OCR 与战术推荐。
- 计分板二值化改为自适应亮度阈值，按截图自身明暗自动调整，提升暗图/偏白截图的识别稳定性。
- 比分解析增加倒计时过滤：忽略 `0:03`、`1:09` 这类带前导零秒数的时钟，避免误判为比分。
