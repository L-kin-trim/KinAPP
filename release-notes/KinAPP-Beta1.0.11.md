# KinAPP Beta1.0.11

## 更新内容

- 首页帖子之间的分隔线改为正常细线，列表浏览更轻量。
- 帖子详情评论区点击回复后自动聚焦输入框并弹出键盘。
- 上线等级展示，首页、帖子详情和“我”页面会按等级显示不同底纹颜色。
- 接入等级经验字段：满级 20 级，每 200 经验升一级。
- 后端经验获取规则已接入：每日签到 +10，发帖 +20，帖子被其他用户点赞 +5。
- 个人资料与登录接口补充等级和经验信息。

## 构建

- APK：`KinAPP-Beta1.0.11.apk`
- 后端：已生成 `luankinstation-0.0.1-SNAPSHOT.jar`
