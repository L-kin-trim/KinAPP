# KinAPP Beta1.0.19

## 更新内容

### 分区（板块）功能
- 分区改为动态管理：发帖时「分区」从后端已创建的分区列表中选择（点击弹出选择框），不再是写死的几个固定项。
- 管理员可在「管理中心 → 分区管理」新增 / 删除分区。
- 首次启动自动初始化默认分区：CS2分区、逃离塔科夫分区、战争雷霆分区。

### 首页帖子分区标签
- 首页每个帖子底部左侧展示所属分区：
  - 道具分享帖固定展示「CS2道具分享」
  - 战术分享帖固定展示「CS2战术分享」
  - 其余帖子展示其所选分区名称

## 服务端
- 新增分区接口：`GET /api/forum/zones`（所有登录用户）、`POST /api/admin/forum/zones`、`DELETE /api/admin/forum/zones/{id}`（管理员）。
