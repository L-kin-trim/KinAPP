# KinAPP Beta1.0.3

对比 GitHub 最新公开版本 `KinAPP Beta1.0.2`，本版本主要更新：

- 新增应用内更新能力：启动后检查 GitHub Releases，发现新 APK 时弹窗展示版本和更新内容，用户确认后下载并调用系统安装器安装。
- 重构首页浏览体验：隐藏顶部功能栏目和帖子操作按钮，首页只保留帖子流；帖子卡片改为标题、时间/分区、正文预览、作者、点赞数和评论数，点击整张卡进入详情。
- 优化帖子详情页：隐藏审核状态、版本、审核备注、可编辑时间和详情工具模块；正文与评论区用灰色分割线分隔，点赞、收藏、举报改为图标入口。
- 新增图片预览：帖子正文图片支持点击进入全屏预览，并可双指缩放和拖动查看。
- 精简收藏库：隐藏个人库、收藏夹入口和资料管理能力模块，收藏库只展示已收藏帖子，点击收藏项进入原帖。
- 增强内容功能：补充帖子、评论、举报、收藏、草稿、站内消息、用户资料、AI 推荐、OCR 记分牌识别和未来功能中心等客户端实现。
- 本地化与界面打磨：统一主要页面中文文案，优化底部导航、按钮布局、帖子卡片间距和移动端显示稳定性。
- 安全清理：发布前排除本地 Gradle 用户目录、崩溃日志、运行 replay 日志和本机配置文件。

已知说明：

- Android 8.0 及以上首次安装 GitHub 下载的 APK 时，系统可能要求用户授予“安装未知应用”权限。
- 本版本 APK 为 Debug 签名包，适合测试分发使用。
