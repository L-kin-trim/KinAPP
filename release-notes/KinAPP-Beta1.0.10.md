# KinAPP Beta1.0.10

对比 `KinAPP Beta1.0.9`，本版本主要更新：

- 帖子详情页正文/评论左右切换增加滑动过渡动画。
- 首页帖子流改为无卡片样式，帖子之间使用粗灰色实线分隔。
- 评论区修复“回复 null”展示问题，主评论不再显示无效回复对象；回复的回复展示为“用户名（回复 用户名）：内容 时间”。
- 主评论新增点赞按钮、点赞数统计，默认按点赞数排序，并支持切换到时间排序；子回复不显示点赞按钮。
- 评论头像缩小，回复区使用更紧凑的分组展示。
- 修复更新检查取 GitHub Release 列表第一项导致漏检高版本的问题，改为按版本号选择最大 APK 发行版。
- 更新检查失败时显示 HTTP 状态和 GitHub 返回内容，方便判断网络或接口问题。
- 发布 APK 改为压缩 release 构建，开启代码压缩与资源裁剪，体积从约 62.6MB 降至约 46.5MB。

服务端同步更新：

- 新增评论点赞表、评论点赞/取消点赞接口、评论点赞数与登录用户点赞状态返回。
- 评论创建时正确记录父评论与被回复用户名。
- 已生成后端 jar：`luankinstation-0.0.1-SNAPSHOT.jar`。

构建产物：

- `KinAPP-Beta1.0.10.apk`
