# KinAPP Beta1.0.18

## 更新内容

### 发帖界面优化
- 帖子类型选中样式反转：当前选中的「道具分享帖 / 战术分享帖 / 日常闲聊帖」改用黑色边框框起来，未选中的不再有黑框（与旧版相反），选中态更醒目。
- 图片选择后新增本地预览：道具分享帖的站位图/瞄点图/落点图各自显示一张缩略图；日常闲聊帖图片上传按选择顺序在下方横向显示所有缩略图，样式与帖子详情页一致。
- 日常闲聊帖将「地图」改为「分区」：提供 CS2分区 / 逃离塔科夫分区 / 战争雷霆分区 三个分区选择，默认 CS2分区；道具分享、战术分享仍保留原有「地图」字段。
