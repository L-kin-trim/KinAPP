# KinAPP Beta1.0.13

## 更新内容

- 修复“我”页面等级与经验显示和数据库实际经验不一致的问题；当前用户等级/经验改为读取签到汇总中的实时成长数据，并兼容 `experience`、`userExperience` 等不同字段名。
- 当后端只返回经验或等级字段缺失时，App 会按每 200 经验 1 级、最高 20 级重新计算展示等级，避免继续显示旧缓存的 0 经验。
- 优化 AI 推荐栏本地 OCR：针对 CS2 计分板的固定位置切分顶部 HUD、计分板主体、上下队伍、玩家名、统计列、比分区和小地图区域，分别进行中英文识别后合并，提高玩家名、经济、K/D/A 与比分提取稳定性。
