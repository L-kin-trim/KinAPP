# KinAPP Beta1.0.5

对比 `KinAPP Beta1.0.4`，本版本主要更新：

- 更新弹窗支持下载进度展示，点击更新后直接进入下载状态，下载完成后立即拉起安装。
- 更新安装包增加本地完整性缓存判断，同版本 APK 已完整下载时会直接安装，避免重复下载。
- 首页帖子预览在时间后增加地图名称，信息顺序为时间、地图、分区。
- 修复点赞请求与接口约定不一致的问题：点赞接口改为无请求体 `POST`，避免向服务端发送多余 JSON body。

点赞问题分析：

- 仓库内只有 Android 客户端代码和后端接口文档，没有服务端工程源码，因此本版本无法生成服务端 jar 包。
- 接口文档声明点赞为 `POST /api/forum/posts/{postId}/like`，没有请求体；此前 APP 会发送 `{}` 请求体。
- 用户看到的 `internal server error` 是服务端返回的 500 文案，但客户端确实存在不符合接口约定的请求方式。本版本已优先修正客户端请求。
