# KinAPP Beta1.0.7

对比 `KinAPP Beta1.0.6`，本版本主要更新：

- 首页支持下拉刷新，用户可以直接刷新帖子流。
- 首页右上角新增搜索入口，支持按标题、地图、点位、道具/战术内容进行搜索，并提供精确搜索开关。
- 首页搜索增加历史记录，历史搜索词会自动保存，并可在搜索弹窗中点击回填。
- 收藏库保留为专门展示用户收藏帖子的页面，新增按地图归档筛选；收藏中出现过几个地图，就显示几个地图筛选项。
- 收藏库右上角新增库内搜索，只对当前用户收藏库内容进行标题、地图、点位和描述匹配。
- 收藏库搜索增加历史记录，历史搜索词可点击复用。
- “我”页面新增当前版本展示和手动检查更新按钮，用户可主动检查 GitHub 最新发行版。
- 更新检查支持手动结果反馈：没有新版本时显示当前版本和最新版本，检查失败时显示失败原因。
