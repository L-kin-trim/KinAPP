# KinAPP Beta1.0.17

## 更新内容

### 发帖
- 发布器页面隐藏「创作辅助工具」一栏，专注帖子类型与正文表单。

### AI 推荐
- 修复 AI 战术推荐输出开头出现大量 `null` 的问题：流式响应中 `content` 为 JSON null 的分片（角色/推理/结束块）不再被错误输出为字符串 `null`。
- 隐藏 OCR 结构化里的「结构化摘要」一栏。

### 计分板 OCR（重做识别方式）
- 放弃按固定 16:9 比例裁切的旧方案，改为基于 ML Kit 文字块包围盒的版面重建：
  - 按纵坐标把识别到的文字元素聚类成「行」，行内再按横坐标从左到右排序，还原每一行的真实阅读顺序，不再因计分板位置/分辨率不同而错位。
  - 比分通过「字号最大、位于左侧的两位数字」识别左右两队大比分。
  - 玩家行沿用「行末固定 5 个数 = 杀敌/死亡/助攻/爆%/伤害，己方多金钱在前」规则，并自动去掉行首的延迟/等级数字，保留如 bj30380773、用户5061991 这类含数字的玩家名。
  - 中文与拉丁两套识别结果择优取用。
- 新增针对真实 Dust II 计分板重建结果的单元测试。
