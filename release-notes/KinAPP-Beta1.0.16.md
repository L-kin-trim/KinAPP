# KinAPP Beta1.0.16

## 更新内容

### 发帖入口
- 点击底部「发帖」导航后直接打开发布器，不再先经过中间的发帖落地页。
- 发帖落地页（左右滑动可见）精简为只保留「发布帖子」卡片，隐藏「创作工具箱」与「草稿箱」。

### 帖子详情图片浏览
- 右上角新增「当前页 / 总页数」数字标识。
- 图片默认按屏幕宽度铺满，左右两侧顶格，不再出现缩放后图片停留在屏幕中间、左右留黑边的情况。
- 平移与缩放都做了边界约束：松手后图片不会越界，始终贴合屏幕边缘。
- 当图片已平移/缩放到水平边界时，继续滑动会切换到上一张 / 下一张图片。
